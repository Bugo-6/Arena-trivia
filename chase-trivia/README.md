# ארנת החידון – טריוויה מרובת משתתפים בזמן אמת

משחק טריוויה בעברית (RTL) בהשראת "המרדף", עם מיתוג ועיצוב מקוריים. React + TypeScript + Vite + Framer Motion, ו-Supabase (Postgres + Realtime + Auth אנונימי) כשרת.

## מה יש בפנים

- **3 מצבי משחק**: המרדף (בניית צבר ← מרדף על לוח ← סיבוב גמר של 60 שניות), כולם נגד כולם (בונוס מהירות), קרב קבוצות.
- **13 מסכים**: דף נחיתה, יצירת חדר, הצטרפות בקוד, לובי, בחירת מצב, קטגוריות ורמת קושי, שאלה עם טיימר, חשיפת תשובה, לוח תוצאות חי, לוח המרדף, סיבוב גמר, מסך מנצח עם קונפטי, היסטוריה וסטטיסטיקות.
- **300 שאלות** ב-10 קטגוריות × 3 רמות קושי (`src/data/questions/*.json`). אין כפילויות בתוך משחק, והתשובות מעורבבות בשרת.
- **צלילים** (מסונתזים ב-WebAudio, אין קבצי אודיו) עם כפתור השתקה.

## הרצה

```bash
npm install
npm run dev:local     # שרת מקומי + האתר, בלי חשבון Supabase. פותחים כמה לשוניות/מכשירים ברשת ומשחקים
```

`dev:local` מריץ את **אותו SQL בדיוק** (`supabase/schema.sql`) על Postgres מוטמע (PGlite), כך שזה מולטיפלייר אמיתי עם ולידציה בצד שרת. כל לשונית היא שחקן נפרד.

## חיבור ל-Supabase (פרודקשן)

1. פותחים פרויקט ב-supabase.com.
2. `Authentication → Sign In / Providers` ← מפעילים **Allow anonymous sign-ins**.
3. `SQL Editor`: מריצים את `supabase/schema.sql`, ואחריו את `supabase/seed.sql`.
4. `cp .env.example .env` ומשלימים `VITE_SUPABASE_URL` ו-`VITE_SUPABASE_ANON_KEY` (Project Settings → API).
5. `npm run dev` לפיתוח, או `npm run build` ופריסה של `dist/` (Vercel / Netlify / Cloudflare Pages). ב-SPA צריך rewrite של כל הנתיבים ל-`index.html`.

מומלץ בפרודקשן: להפעיל CAPTCHA להתחברות אנונימית (Auth → Attack Protection), ולתזמן ניקוי חדרים ישנים עם pg_cron: `select cron.schedule('0 * * * *', 'select public.cleanup_old_rooms()');`

## אבטחה ואמינות

- ללקוחות **אין** גישת כתיבה לשום טבלה, ואין גישת קריאה לשאלות, לתשובות הנכונות ולתשובות של שחקנים אחרים (RLS). הכול עובר דרך פונקציות `SECURITY DEFINER` שבודקות `auth.uid()`, מצב החדר והקלט.
- הניקוד מחושב רק בשרת. תשובה אחת לשאלה (מפתח ראשי), תשובה מתקבלת רק בחלון הזמן של השאלה, רק המארח מקדם את המשחק.
- התשובה הנכונה נחשפת לכולם רק בשלב החשיפה, אחרי שהשאלה נסגרה.
- שעון אחד: כל הטיימרים נמדדים לפי שעון השרת, עם סנכרון בצד לקוח.
- ניתוקים: שחקן שרענן את הדף חוזר לאותו משחק. מארח שנעלם 25 שניות מוחלף אוטומטית, ושחקן מנותק לא חוסם סיום שאלה.

## בדיקות

```bash
npm run test:server   # שרת: אבטחה, 3 מצבי משחק, ניתוקים (על Postgres אמיתי)
npm run dev:test      # בטרמינל נפרד: שרת מקומי במצב בדיקה
npm run test:e2e      # בדפדפן אמיתי: 3 שחקנים נפרדים משחקים משחק שלם בכל מצב
```

## להוסיף שאלות

מוסיפים אובייקט לאחד הקבצים ב-`src/data/questions/` (**התשובה הנכונה ראשונה**, המשחק מערבב), מריצים `npm run seed:build`, ואז מריצים שוב את `supabase/seed.sql` (אפשר שוב ושוב, כפילויות מדולגות).

```json
{ "q": "מהי בירת צרפת?", "a": ["פריז", "ליון", "מרסיי", "ניס"], "cat": "geography", "diff": "easy" }
```
